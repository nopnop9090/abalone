# Abalone

Abalone-Clone (Brettspiel) in zwei Varianten – je ein eigener Branch:

| Branch | Inhalt |
|---|---|
| [`node`](../../tree/node) | Ursprüngliche Version: Node.js-Server (`ws`) + Browser-UI, Computer-/LLM-Gegner, Online-Räume per WebSocket. |
| [`standalone`](../../tree/standalone) | Neuentwicklung: Rust-Executable ohne externe Abhängigkeiten, eingebettete Browser-UI, HTTP/JSON-Interface für externe Gegner (Browser oder Executable/Bot). |

Dieser Branch (`main`) enthält nur diese Übersicht und die Lizenz.
